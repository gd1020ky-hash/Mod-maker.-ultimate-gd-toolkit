# SM Macro

SM Macro is a Geometry Dash utility project focused on accurate frame-based macro recording,
playback, timeline inspection, and future Pathfinder / AI-assisted level-building features.

## V0.1.0

The first milestone focuses on the core macro data model and build foundation.

Planned progression includes:

- `.sm` native macro format
- frame-accurate press/release events
- reliable playback
- frame counter and timeline tools
- Pathfinder
- AI-assisted gameplay generation
- AI-assisted decoration
- music synchronization
- level quality checking
